# Quick Reference — Read This Before You Walk In

## The 60-second pre-flight
- [ ] My BATNA, one sentence: "If no deal, I will ______"
- [ ] Reservation point written down. Target set high and justified.
- [ ] Their likely BATNA, clock, and audience — who must they justify this to?
- [ ] 3 predictions written (their open / their floor / their hidden interest)
- [ ] 5 labels + accusation audit drafted. 3 calibrated questions ready.
- [ ] Ackerman ladder set (65 → 85 → 95 → 100%, precise final)
- [ ] Culture check done (see grid below)
- [ ] Breathe. Slow voice. Their turn to talk.

## The core moves (Voss)
| Situation | Move | Script |
|---|---|---|
| Get them talking | Mirror (last 1–3 words) + 4s silence | "...the budget cycle?" |
| Emotion in the room | Label it | "It seems like ______" |
| Hard ask coming | Accusation audit | "You're going to think I'm ______" |
| Need engagement | No-oriented question | "Have you given up on ______?" / "Is it a bad time?" |
| They state a position | Calibrated question | "How did you arrive at that?" |
| Their demand is impossible | The gentle no | "How am I supposed to do that?" |
| Feel understood → breakthrough | Summary until... | "That's right." (NOT "you're right") |
| Vague yes | Force the how, ×3 | "How will we know we're on track?" |
| Offensive offer | Calm refusal | "I'm sorry, that just doesn't work for me." + silence |
| Attacked / provoked | Balcony + DJ voice | Slow down. Drop pitch. Label their anger. |

## Hardball counters
| Their tactic | Your counter |
|---|---|
| Extreme anchor | Don't counter yet. Label + "How did you get to that number?" Return to YOUR prepared target. |
| Fake deadline | "If it's good today, it's good Thursday." Most deadlines are self-imposed. |
| Good cop / bad cop | Name it gently: "You two are quite a team." Negotiate with the interests, not the theater. |
| "That's our policy" | "Who has the authority to make exceptions?" + normative leverage (their own promises). |
| Take it or leave it | Reframe as opening: "That's one option. Before we settle, help me understand ______." |
| Nibbling after agreement | Cheerful reciprocity: "Happy to — what shall we trade for it?" |
| Silence as pressure | Out-sit it. The next number spoken after silence is usually a concession — don't let it be yours. |
| Anger / intimidation | Balcony. "It seems like this really frustrated you." Never match heat. |
| Low-ball (terms degrade after yes) | "Knowing what I know now, that earlier yes no longer applies." |

## Cialdini in one breath
**Reciprocity** (give first; concessions get repaid) · **Consistency** (small yeses, their words, in writing) · **Social proof** (similar others) · **Authority** (arranged credibility + admitted weakness + precision) · **Liking** (similarity, honest praise, cooperation) · **Scarcity** (real limits, loss framing) · **Unity** (shared identity, "advice makes partners").
Defense = notice which one is being aimed at you, and re-decide on paper, alone.

## Reading people in one breath
Baseline first (5 min neutral topics) → read **deviations in clusters, timed to topics** → feet/torso most honest, face least → pacifying = stress marker, not lie detector → words vs. tone/body conflict: believe tone/body, label the gap → type them (Analyst: data + time · Accommodator: warmth + pin down specifics · Assertive: let them talk, then be direct) → when behavior seems crazy, your model is missing a variable — hunt the Black Swan.

## The phrase bank
- "It seems like there's something here I'm missing."
- "What's the biggest challenge you're facing with this?"
- "How am I supposed to do that?"
- "What would need to be true for this to work for you?"
- "Have you given up on ______?"
- "If I could do X, could you do Y?"  (never concede naked)
- "I want you to feel treated fairly — stop me if anything seems off."
- "How does this affect the rest of your team?" / "Who else needs to be comfortable with this?"
- "What happens if we don't reach a deal?"  (their BATNA probe)
- "That's one option — what else could we consider?"
- "If you were in my position, how would you structure this?"  (advice → unity)
- "I'm afraid that's not something we could do — here's what we CAN do..."
- "How can we solve this problem together?"

## The five laws (never violate)
1. Discovery beats battle — the curious one wins.
2. Power = BATNA. Build it before you need it.
3. Emotion first, logic second — theirs and yours.
4. "No deal" stays on your menu, always.
5. Culture changes the *how*, never the *what*.
